# Specs and prompts for the AI sessions

ETHGlobal asks teams that build from specs to commit the specs, prompts and plans they used. These are the written instructions given to Pawan's Claude Code sessions:

| File | What it is |
|---|---|
| [`BRIEF.md`](BRIEF.md) | The brief every session read first: the project, the hero moment, team boundaries, git rules, sponsor lessons |
| [`DECISIONS.md`](DECISIONS.md) | The decisions log. Decisions were made by Pawan and the team, and the log overrides any message |
| [`prompts/`](prompts/) | One task prompt per session: `dy-0g`, `dy-arc`, `dy-arkiv`, `dy-web`, `dy-demo` |

The manager session gave its follow-up instructions as short messages, based on these files.

These are copies taken on Fri 6 Nov (IST) and refreshed before submission. Local file paths and the locations of test secrets were removed, along with a few purely internal notes. Otherwise the text is unchanged.
